# Reporting a new issue

For a new finding, include whatever is readily available:

- Candidate name and, if available, ROM SHA-256 from `manifest.json`.
- Console/cartridge or emulator, Expansion Pak, and save-type settings.
- Where the issue occurs, the actions immediately before it, and expected result.
- A photo or exact text for wording, layout, or artwork issues.
- For a freeze, crash, or conversation loop: the last visible dialogue, whether
  movement/audio continues, and whether an existing or new town is affected.
- If relevant, the game date/time, villager, shop stage, or event.
- Whether the save was created on this candidate or carried over from another.

Do not risk your only save trying to reproduce a fault. Preserve a backup first;
do not perform destructive Pak operations or enable debug menus for a report.
Saves, ROMs, and extracted game assets must not be posted publicly. Ordinary
reports can use descriptions and screenshots without attaching those files.

Previously accepted fixes and ordinary save/restart/reload do not need repeating.
Broad playtesting can proceed normally; a report does not require an exhaustive
test matrix or a fresh town. Crashes, save damage, and blocked progression take
priority over cosmetic issues.
