# Complete bilingual item-name batch

## Installed scope

`build/sheet-items-pilot` installs 327 new reviewed identities in 834 complete
sixteen-byte fields. All 112 new fields that fit ten bytes also enter native
storage. Totals are 4,397 wider fields and 13,710 ordinary edits, with every
earlier entry retained. The [specification](../../specs/SHEET_ITEM_NAMES.md)
defines exact local-source/sheet binding, changed-design exclusions, and the
open carried/placed spelling conflicts.

The new 8,576-byte treasure article profile covers all 4,397 translated fields;
147 remain unavailable. Its complete creator retains 58,144 bytes, 848 relocation
bytes, all machine code/symbols, and the original workspace. Independent creator
builds agree on image, relocations, and manifest. The full ROM changes only the
native name bank, existing wider resource, creator article data, and the resident
creator-CRC configuration. Reader code, earlier letter resources/actors, font,
saved layout, and memory bounds remain unchanged.

## Reproduction and required continuation

Generate candidates with the full seasonal-runtime flags and default drafts,
outputting `build/sheet-items-candidates`. Generate wider names with
`tools/extended_items.py --rom 'local/rom/Doubutsu no Mori (Japan).z64'
--output build/sheet-items-resource`. Build articles with
`tools/item_articles.py --names build/sheet-items-resource
--output build/sheet-items-articles`. Build the complete creator with every
preceding flag plus `--notice-treasure --notice-owner --notice-seasonal
--mail-glyphs --item-articles build/sheet-items-articles/articles.bin`,
using `build/notice-seasonal-runtime/module.json`. The full ROM recipe is
`bash tools/build_sheet_items_pilot.sh`; `tools/sheet_item_scenario.py` generates
the native plan. Generated game/reference data and all ROMs remain ignored.

Resolve the remaining names, including repeated stationery reference groups,
native-specific designs, numbered placed shirts, dot spelling, and accented/
carried-versus-placed fields. Continue all remaining general strings, letters,
full-name callers, editorial review, normal save/travel/gameplay validation,
patch-only release, title images, and the GameCube-style keyboard. The complete
project remains active, and original hardware still requires actual evidence.
