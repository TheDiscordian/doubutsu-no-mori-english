    A TRAIN RIDE AWAY

    Visiting a friend’s village.

    Use the same V3 patcher version, imports, and behaviour settings in both villages. Share an exported settings file, then each build your own ROM. Compare the finished ROM SHA-256 checksums to confirm you built the same game. Keep separate saves for each town, and back them up before travelling.

    Matching settings aren’t a promise that every import can travel.

    Added fish and insect records have Controller Pak passport support between compatible V3 profiles. Travel with other imported catalogue items and console-game records remains unfinished. Ordinary end-to-end village visits with the complete import set are unverified; sharing settings does not remove those limits. Do not use a V3 passport or save with V2 or a V3 build lacking the matching import and save/passport support.
